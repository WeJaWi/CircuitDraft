# Changelog

## 0.1.0-alpha — 2026-10-23

First public alpha. A bare-bones prototype released to find out whether people want a native Mac schematic editor with MCP automation.

- Native SwiftUI/AppKit editor for Apple silicon.
- Seven simplified symbols, basic orthogonal wires, pages and properties.
- JSON persistence, undo/redo, parts lists, CSV, SVG and PDF exports.
- Local automation bridge and optional MCP companion.
- Pinned Canary-ECAD EPLAN MCP integration for discovery; live EPLAN execution requires Windows EPLAN.
- 50 automated model/export/automation checks and real MCP/interface checks.

Missing: EPLAN file compatibility, simulation, rules checking, automatic junctions, routing around obstacles, advanced ECAD features, Intel build and notarized distribution.
